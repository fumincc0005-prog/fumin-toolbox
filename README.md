# 富民營造工具箱（離線版）

改自「酪梨營造工具箱」，給富民營造工地人員隨身使用：**不需要網路、不需要伺服器、不需要登入**。
填寫的檢查表只存在自己的手機／平板／筆電裡，填好產生 PDF 即可列印。

## 功能
- 自主檢查表：48 份內建範本＋自訂範本，中文／越南文切換，逐項 ○ ✕ ／、手寫簽名
- 列印時可選「表格格式」：**富民版格式**（預設）或原格式；列印語言中文／越南文／中越對照
- 平面圖巡查筆記：在平面圖上點位置記缺失、照片、追蹤改善
- 備份匯出／匯入（也可匯入酪梨工具箱的備份檔，搬舊資料用）

## 發佈（要先放到 HTTPS 網址，手機才能安裝與離線使用）
建議放在**公司自己控管**的 GitHub 帳號：
1. 建立新的 repository（例如 `fumin-toolbox`），把本資料夾內所有檔案（含 `.nojekyll`）上傳
2. Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` → Save
3. 幾分鐘後網址為 `https://<公司帳號>.github.io/fumin-toolbox/`

> 不要放在個人帳號，也不要和其他網頁放在同一個 `xxx.github.io` 帳號底下（同網域的網頁共用瀏覽器儲存空間）。

## 安裝到手機
- Android：Chrome →「⋮」→「安裝應用程式」
- iPhone：Safari →「分享」→「加入主畫面」
- 右上角顯示「✓ 可離線使用」即完成

## 更新程式後
修改任何檔案後，把 `sw.js` 的 `VERSION` 改成新的值（例如 `fumin-1151120a`），手機下次連網就會換新版。

## 資安設定（請保留）
- `index.html` 的 Content-Security-Policy：只允許本網站自己的程式、禁止連到外部網站
- `offline-store.js` 的匯入清理（cleanForm）：避免惡意備份檔夾帶程式碼
- `plan-notes.js` 的 `isEvalSupported: false`：避免惡意 PDF（CVE-2024-4367）
- 備份檔含所有簽名，請存私人資料夾，不要傳到群組
